# 健檢發現腎囊腫，要緊嗎？會不會變成癌症？

> 腹部超音波報告寫著「腎囊腫」，是健檢最常見的發現之一。**絕大多數是單純性腎囊腫，是裡面裝著清水的良性小水泡，不會變癌、通常也不影響腎功能。**這篇說明單純囊腫和「複雜性囊腫」怎麼分、Bosniak 分級各代表什麼、什麼時候要追蹤或做電腦斷層，以及它和多囊腎有什麼不一樣。

分類：檢查數值

重點問題：超音波說我有腎囊腫，需要開刀或吃藥嗎？會不會變成癌症？
重點答案：**單純性腎囊腫是良性的，不需要治療，也不會變成癌症**，而且年紀越大越常見。要注意的是**「複雜性囊腫」**——壁變厚、有隔間、有鈣化或實心的部分——這類需要用顯影的電腦斷層或磁振造影，依 **Bosniak 分級**決定是追蹤還是處理。**兩邊腎臟都有很多顆、腎臟變大、或有家族史**，則要考慮多囊腎，那是不同的疾病。
重點行動：看報告上是不是寫「單純性（simple）」囊腫；若是，**不必治療、不必特別追蹤**，下次健檢照做即可。若寫「複雜性」「有隔間」「有鈣化」「建議進一步檢查」，請**到泌尿科或腎臟科安排顯影檢查**。不需要因為囊腫改變飲食或吃保健食品。

「醫師，我的腎臟長了一顆水泡，要不要拿掉？」

腎囊腫是腹部超音波最常見的發現之一，而且隨著年紀增加越來越常見——到了五六十歲以上，在健檢報告上看到它一點也不稀奇。它聽起來可怕，因為「腎臟裡長了東西」很容易讓人聯想到腫瘤。

但多數時候，答案是：**不用拿、不用吃藥、不用改變生活。** 真正需要分辨的，是報告上寫的到底是哪一種囊腫。

## 腎囊腫是什麼

腎囊腫是**長在腎臟上、外面一層薄膜、裡面裝著液體**的小囊袋。它們通常：

- 長在腎臟的表層（皮質）
- 大小從幾毫米到幾公分不等
- 可以單獨一顆，也可以兩邊各有幾顆
- **成因目前仍不完全清楚**，被認為和腎小管隨年紀出現的小變化有關

最重要的是：**單純性腎囊腫不是腫瘤，不會轉移，也不會變成癌症。**

## 單純性和複雜性：報告上最重要的那幾個字

超音波看囊腫，看的是它的「外觀」：

| | 單純性囊腫 | 複雜性囊腫 |
|---|---|---|
| **囊壁** | 薄、光滑 | 變厚或不規則 |
| **內容物** | 清澈液體，超音波下是全黑 | 有回音、混濁、有碎屑 |
| **隔間** | 沒有 | 有一條或多條隔間 |
| **鈣化** | 沒有 | 可能有 |
| **實心部分** | 沒有 | 可能有，或有血流 |
| **意義** | **良性，不需追蹤** | 需要進一步檢查，依分級決定 |

**報告上如果寫的是「simple cyst」「單純性腎囊腫」，你可以放心。** 如果出現「complex」「複雜性」「septation（隔間）」「calcification（鈣化）」「solid component（實心部分）」「建議進一步檢查」等字眼，就要往下看。

## Bosniak 分級：複雜性囊腫的評估標準

複雜性囊腫通常需要**打顯影劑的電腦斷層或磁振造影**，再依照國際通用的 **Bosniak 分級**來判斷。這套分級在 2019 年更新過，概念如下：

| 分級 | 樣子 | 一般處理方向 |
|---|---|---|
| **I** | 單純性囊腫 | 良性，不需追蹤 |
| **II** | 少許細隔間、細小鈣化，或特定的小型高密度囊腫 | 良性，通常不需追蹤 |
| **IIF** | 介於中間，特徵稍多（F 是 follow-up） | **定期影像追蹤**，多數長期穩定 |
| **III** | 囊壁或隔間變厚、不規則 | 惡性的機會明顯升高，**和泌尿科討論手術或積極追蹤** |
| **IV** | 有明確的實心、會顯影的部分 | 多數為惡性，**通常建議手術** |

幾個重點：

- **超音波不能完整分級**，它只能說「這顆看起來單純」或「這顆看起來不單純」。複雜的需要顯影檢查才分得清楚
- **IIF 的「F」代表追蹤**，不是「快要變癌」。多數 IIF 的囊腫多年都沒有變化
- III、IV 級的處理，是泌尿科醫師依大小、位置、年紀與整體健康一起決定，現在很多可以用保留腎臟的部分切除

腎功能不好的人要做顯影檢查，常會擔心顯影劑傷腎。實際的風險與準備方式見[打顯影劑會傷腎嗎](/articles/contrast-ct-kidney.html)。

## 腎囊腫和多囊腎，不是同一件事

這是最常見的混淆。

| | 單純性腎囊腫 | 多囊腎（體染色體顯性多囊腎病） |
|---|---|---|
| **原因** | 隨年紀出現，非遺傳 | **遺傳疾病** |
| **數量** | 一顆到幾顆 | **兩側腎臟都有很多顆**，隨年紀越來越多 |
| **腎臟大小** | 正常 | **逐漸變大** |
| **家族史** | 通常沒有 | 父母之一常有，子女有一半機會遺傳 |
| **腎功能** | 通常不受影響 | 會逐漸下降，部分人最後需要透析 |
| **其他** | — | 可能合併肝囊腫、高血壓、腦血管瘤 |

如果你是**年輕時就發現多顆囊腫、兩邊都有、腎臟偏大，或家裡有人洗腎、有人是多囊腎**，請到腎臟科評估。詳細說明見[多囊腎那一篇](/articles/polycystic-kidney-disease.html)。

另一種情況是**長期透析的病人**，腎臟萎縮後常出現很多小囊腫（後天性囊腫性腎病），這類病人的腎臟癌風險較高，需要依醫師建議定期影像追蹤。

## 單純囊腫會造成什麼問題嗎？

**絕大多數不會有任何症狀**，是剛好在健檢中被看到。少數情況：

- **很大的囊腫**（例如超過好幾公分），可能壓迫造成腰部悶痛，或很少見地壓迫到尿路
- **囊腫出血或感染**：突然腰痛、發燒、血尿，需要就醫
- **囊腫破裂**：非常少見

**單純性囊腫通常不會影響腎功能，也不會造成高血壓**（極少數壓迫到血管的大型囊腫例外）。

## 需要治療嗎？

**沒有症狀的單純性囊腫，不需要任何治療。** 「拿掉」只在少數情況才考慮：

- 囊腫很大，造成明確的疼痛或壓迫
- 反覆感染或出血

處理方式包括**超音波導引抽吸並注射硬化劑**，或**腹腔鏡把囊腫的頂部切開（去頂術）**。單純抽吸而不打硬化劑，囊液常常會再長回來。

**沒有藥物可以讓囊腫消失，也沒有飲食或保健食品被證實能讓它變小。** 網路上「消囊腫」的產品，請不要花這個錢。

## 單純囊腫需要追蹤嗎？

**真正的單純性囊腫（Bosniak I），國際上的共識是不需要專門安排影像追蹤。** 照一般的健檢頻率做腹部超音波就可以了。

囊腫在幾年之間**慢慢變大一些是常見的**，單純「變大」本身不代表變壞。真正需要注意的是**外觀改變**——出現隔間、壁變厚、實心部分。

## 常見問題與誤解

### 腎囊腫會變成腎臟癌嗎？

**單純性囊腫不會。** 需要注意的是本來就屬於「複雜性」的囊腫，它們有一部分其實是囊性的腫瘤，這就是 Bosniak 分級要找出來的。所以重點不是「會不會變」，而是**一開始就分清楚它是哪一種**。

### 腎囊腫要多喝水嗎？要少吃什麼嗎？

**單純性囊腫和飲食、喝水都沒有關係。** 不需要特別多喝水、也不需要忌口。多囊腎的飲水建議則另有討論，請見多囊腎那一篇。

### 囊腫比上次大了，是不是要處理？

單純性囊腫隨時間慢慢變大很常見，**只要外觀仍然單純、沒有症狀，就不需要處理**。如果報告寫到外觀改變，或建議進一步檢查，再安排顯影檢查。

### 報告寫「腎臟有鈣化點」，和囊腫有關嗎？

不一定。腎臟的鈣化點可能是小結石、舊的發炎痕跡，也可能是囊腫壁上的鈣化。**長在囊腫上的鈣化屬於「複雜性」特徵**，需要看完整的影像判斷；單獨的小鈣化點多數是小結石，見[腎結石那一篇](/articles/kidney-stones-prevention.html)。

### 一邊腎臟有好幾顆囊腫，是多囊腎嗎？

**不一定。** 單純性囊腫也可以多顆。多囊腎的診斷會依年齡、兩側的囊腫數量和家族史來判斷——例如年輕人就有多顆、兩側都有、家族裡有人罹患。有疑問請到腎臟科評估。

## 現在可以做的三件事

- **看清楚報告上寫的是「單純性」還是「複雜性」。** 單純性是良性的，不需要治療，也不需要另外追蹤，照常健檢就好。
- **出現「複雜性」「隔間」「鈣化」「實心」「建議進一步檢查」，就安排顯影的電腦斷層或磁振造影。** 依 Bosniak 分級，由泌尿科決定是追蹤還是處理。
- **兩側多顆、腎臟變大、或家族有人洗腎，請到腎臟科評估多囊腎。** 不要花錢買宣稱能消囊腫的產品——沒有任何一種被證實有效。
