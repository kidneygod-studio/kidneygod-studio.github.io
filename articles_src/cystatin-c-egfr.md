# 肌酸酐算出來的腎功能不準怎麼辦？胱抑素 C 與 CKD-EPI cr-cys 公式

> 健身族的 eGFR 被低估、長輩的 eGFR 被高估——問題不在檢驗做錯，而在公式用的原料是肌肉的產物。這篇說明胱抑素 C 是什麼、CKD-EPI 2021 的三個公式差在哪裡、哪些人真的需要加驗，以及兩個數字差很多時代表什麼。

分類：檢查數值

重點問題：我肌肉量偏高（或偏低），抽血算出來的 eGFR 還能相信嗎？
重點答案：**不一定。** eGFR 是用肌酸酐算的，而肌酸酐來自肌肉——肌肉量偏離平均時，誤差不是隨機的，而是**固定往一個方向偏**。這種情況下可以加驗**胱抑素 C（cystatin C）**，並改用把兩者一起算的 **CKD-EPI 2021 cr-cys 合併公式**，準確度優於單用任何一項。
重點行動：如果你屬於下面那幾種族群，而且**這個數字要拿來做決定**（轉診、調藥、捐腎評估），就值得開口問醫師能不能加驗胱抑素 C；平時追蹤趨勢則不必每次都驗。

「醫師，我每天重訓，是不是因為這樣肌酸酐才偏高？」

「我媽 80 歲了，瘦到只剩骨頭，報告上 eGFR 卻寫 75，這樣算正常嗎？」

這兩個問題問的其實是同一件事：**當一個人的肌肉量偏離平均值，用肌酸酐算出來的腎功能就會失準。** 而且失準的方向是可以預測的——這正是它麻煩的地方，也是它有解的地方。

## 問題出在原料，不是出在檢驗

先把上一篇（[eGFR 是什麼](/articles/egfr-meaning-ckd-stages.html)）的重點接起來：eGFR 不是量出來的，是**算**出來的。抽血驗的是肌酸酐，再套公式推估腎絲球每分鐘過濾多少毫升的血。

肌酸酐是肌肉裡的肌酸代謝後的產物。它每天以相對穩定的速度產生，由腎臟排出——**只要產生速度穩定，血中濃度就能反映排出能力**。

問題就在這個前提。公式假設「同年齡、同性別的人，肌肉量差不多」。這個假設對大多數人成立，對兩端的人不成立：

- **肌肉量高的人**（重訓者、勞力工作者）產生的肌酸酐比同齡人多，血中濃度自然高，公式便以為腎臟排不掉，**把 eGFR 算低**
- **肌肉量低的人**（肌少症長者、長期臥床、營養不良、截肢、脊髓損傷）產生得少，血中濃度低，公式以為腎臟排得很好，**把 eGFR 算高**

這裡有一件事很關鍵：**這種偏差不會自己抵銷**。

如果只是抽血當天的小波動，多驗幾次就平均掉了。但肌肉量造成的偏差不是波動，它每一次都往同一邊偏。一位瘦到幾乎沒有肌肉的長輩，這個月驗、下個月驗、明年再驗，eGFR 都會偏高——驗一百次也一樣。所以「再抽一次看看」在這裡沒有用。

而這兩種偏差的後果，嚴重程度差很多。

健身的人被算低，頂多是虛驚一場。跑一趟腎臟科、多做幾項檢查，最後發現沒事。麻煩，但不危險。

反過來就不是這樣了。肌肉量很少的長輩被算高，意思是**腎功能其實已經不好，報告卻告訴他沒事**——該轉診的沒轉、該減量的藥沒減、該開始準備的事一路往後延。等到終於被發現，通常已經過了一段時間。

我真正擔心的一直是後面這一種。

## 胱抑素 C：換一種原料

胱抑素 C（cystatin C）是一個小分子蛋白質，特性正好補上肌酸酐的缺口：

- **全身有細胞核的細胞都會製造**，速度相對恆定——不是肌肉的專利
- 分子夠小，在腎絲球**自由過濾**
- 過濾後幾乎全部被近端腎小管**再吸收並分解**，不會回到血液，也不會經由腎小管額外分泌

翻成白話：它的產生量不看你有幾公斤肌肉，而它從血中消失的速度幾乎只取決於腎絲球過濾了多少。所以血中胱抑素 C 越高，代表過濾能力越差——而且這個關係**不受肌肉量影響**。

這也解釋了為什麼它不是拿來取代肌酸酐，而是拿來**交叉驗證**。兩把尺各有各的誤差來源，剛好不重疊。

## CKD-EPI 2021：三個公式，不是一個

2021 年發表的 CKD-EPI 系列其實是三條公式，很多人只知道第一條：

| 公式 | 用什麼算 | 適用時機 |
|---|---|---|
| **CKD-EPI 2021 cr** | 肌酸酐 | 一般篩檢與追蹤的預設 |
| **CKD-EPI 2021 cys** | 胱抑素 C | 肌酸酐明確不可靠時 |
| **CKD-EPI 2021 cr-cys** | 兩者合併 | **需要準確度時的首選** |

2021 這一版最廣為人知的改變，是**拿掉了人種係數**。舊公式會給黑人族群一個較高的估算值，這個修正缺乏生理學基礎，且可能讓該轉診、該評估移植的人被延後——所以被移除。

但對台灣讀者更實際的，是第三條：**合併公式的準確度優於單用任何一項**。原因不難理解——兩個獨立的估計值取共識，各自的偏移會互相抵銷一部分。KDIGO 2024 慢性腎臟病指引也建議：當以肌酸酐為基礎的 eGFR 可能不準確時，用胱抑素 C 來確認。

要注意的是，**合併公式需要同一次抽血的兩個數值**。不能拿三個月前的肌酸酐配今天的胱抑素 C 去套，那算出來的東西沒有意義。

## 誰真的需要加驗

不是每個人都需要。多數人用肌酸酐追蹤趨勢就夠了。真正值得加驗的，是「**肌酸酐可能說謊，而這個數字要拿來做決定**」的情況：

**肌肉量偏離平均**

- 規律重訓、健美、健力，或體型明顯壯碩者
- 肌少症、衰弱症的長者
- 長期臥床、中風後、脊髓損傷
- 截肢
- 嚴重營養不良、癌症惡病質
- 極端 BMI（過瘦或重度肥胖）

**飲食造成短期偏移**

- 抽血前吃了大量肉類（尤其燉煮過的肉，肌酸酐含量高）
- 長期補充肌酸（creatine）
- 嚴格素食者（肌酸酐產生量偏低，可能被高估腎功能）

**數字要拿來做重要決定**

- 決定要不要轉診腎臟科、要不要開始準備透析通路
- **依腎功能調整藥物劑量**——化療藥、部分抗生素、直接口服抗凝血劑（DOAC），這些藥算錯劑量的代價很高
- 活體腎臟捐贈的捐贈者評估
- 顯影劑檢查前的風險評估

**兩個系統的數字對不起來**

- eGFR 看起來正常，但有蛋白尿、貧血、或超音波看到腎臟縮小
- 肌酸酐忽高忽低，臨床上找不到解釋

如果你不在上面任何一類，也沒有要做上面任何一種決定，那按時追蹤肌酸酐與**尿液白蛋白（UACR）**才是重點。加驗胱抑素 C 不會讓沒有的問題浮現。

## 兩個數字差很多，代表什麼

有時候加驗之後會出現一個尷尬的結果：肌酸酐算的 eGFR 是 75，胱抑素 C 算的是 48。哪一個是真的？

第一步是找有沒有可解釋的理由。肌肉量偏高會把 cr 那一邊往上推、把差距拉開；反過來，甲狀腺功能異常或正在用類固醇則會影響 cys 那一邊。找得到理由，就往合理的那一邊靠，或直接用合併公式。

但近年累積的觀察是：**當兩者差距很大時，這個差距本身就帶有預後訊息**。研究發現，胱抑素 C 算出來明顯低於肌酸酐算出來的人（也就是「差距往壞的方向」），死亡率與心血管事件風險較高。這被認為與肌肉量流失、慢性發炎等狀況有關——換句話說，那個落差不只是測量問題，它可能正在告訴你一些關於整體健康狀態的事。

所以差距大的時候，不要只想著「取哪一個數字」，也值得問一句：**為什麼會差這麼多？**

## 胱抑素 C 也不是完美的尺

它解決了肌肉量的問題，但它自己有另一組干擾因子。誠實把它列出來，才知道什麼時候不能只信它：

- **甲狀腺功能**：甲狀腺亢進會使胱抑素 C 上升、低下則下降
- **類固醇**：高劑量會使它上升
- **甲狀腺以外的發炎狀態**：CRP 明顯上升時也可能偏高
- **吸菸與肥胖**：與濃度上升有關
- **極高的細胞更新率**：例如部分惡性腫瘤

看出重點了嗎——這些干擾因子和肌酸酐的（肌肉量、飲食、藥物）**幾乎完全不重疊**。這正是「兩個一起看」比「換一個看」更有價值的理由。當兩把尺的誤差來源不同，兩者一致就令人放心，兩者不一致就是一個需要解釋的線索。

## 在台灣實際要怎麼問

胱抑素 C 在台灣多數院所**不是常規項目**，也不會出現在一般健檢套組裡。是否給付、要不要自費、費用多少，各家院所與情境不同——這件事請直接問開單的醫師或檢驗科，不要憑網路上的說法預設。

比較實際的做法是把「為什麼需要」講清楚，而不是指定要做什麼檢查。例如：

> 「我每週重訓五天、有補充肌酸，這次 eGFR 是 58。我想知道這個數字有沒有可能是被肌肉量影響的？如果不確定，有沒有辦法確認？」

> 「我媽媽 82 歲，體重只有 40 公斤，幾乎沒有肌肉。她的 eGFR 報告是 70，但有貧血也有蛋白尿。這個數字會不會其實高估了？」

這樣問，醫師能直接判斷有沒有必要加驗，也比「我要驗胱抑素 C」更容易得到有用的回答。

## 常見問題與誤解

### 胱抑素 C 是不是比較準，以後都驗這個就好？

不是。單用胱抑素 C 的準確度並沒有系統性地優於單用肌酸酐，**準確度最高的是兩者合併的公式**。而且它有自己的干擾因子（甲狀腺、類固醇、發炎），單獨依賴同樣會被誤導。它的價值在於提供第二個獨立的角度，不是取代第一個。

### 我在重訓，是不是應該停掉才去抽血？

不需要為了數字停止運動。運動對血壓、血糖與心血管的好處是明確的，遠大於一次檢驗數字的困擾。實務上的做法是：**抽血前 24–48 小時避開劇烈運動、暫停肌酸補充劑、前一餐避免大量肉類**，並且讓醫師知道你的運動習慣。如果仍然不確定，那才是加驗胱抑素 C 的時機。

### 加驗之後，是不是就能確定腎功能了？

它讓估算更接近真實，但**仍然是估算**。真正精準的測量需要注射特定物質再連續採血，臨床上很少做。而且腎功能的評估從來不是只看一個數字——蛋白尿（UACR）、影像、病史、變化趨勢，缺一不可。

### 肌酸酐算的 eGFR 正常，就不用管了嗎？

這是最危險的誤解之一，而且和肌肉量無關。**eGFR 正常不等於腎臟沒事**——早期腎損傷常常先表現為蛋白尿，此時 eGFR 還可以完全正常。糖尿病或高血壓的人，每年至少要驗一次 UACR，這件事比爭論用哪個公式更重要。

### 為什麼健檢報告上從來沒看過這一項？

因為它不是常規篩檢項目。一般健檢的目的是在大量無症狀的人裡篩出可能有問題的人，肌酸酐便宜、普及、對多數人夠用。胱抑素 C 是**針對特定情境的補充工具**，不是升級版的健檢套餐。

### 那 CKD-EPI 2021 和舊的公式差多少？

對多數台灣人來說，去除人種係數這一項本身影響不大（那個係數本來就只套用在黑人族群）。真正值得注意的是**你的報告用的是哪一版公式**——不同版本算出來的數字會有落差，跨院所或跨年度比較趨勢時，要確認是同一把尺。這一點問檢驗科通常問得到。

## 現在可以做的三件事

- **先確認自己是不是「肌酸酐可能說謊」的族群**。如果你只是一般上班族、體型中等、沒有特殊病史，那不必為這件事焦慮——按時追蹤肌酸酐與 UACR 就夠了。
- **如果是，把「為什麼懷疑」講給醫師聽，而不是指定要驗什麼**。重訓習慣、肌酸補充、體重變化、臥床時間，這些資訊比你要求的檢查項目更有價值。
- **不論肌肉量如何，把尿液白蛋白（UACR）補上去**。這是本篇最該帶走的一句話：關於「用哪個公式算 eGFR」的所有討論，重要性都比不上「有沒有驗蛋白尿」。eGFR 要等腎臟撐不住才會動，UACR 有機會提早好幾年告訴你。
