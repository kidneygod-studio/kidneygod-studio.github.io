# 中藥會傷腎嗎？馬兜鈴酸、偏方與楊桃，腎友要知道的事

> 「吃中藥會不會傷腎？」是腎臟科門診最常被問的問題之一。答案不是簡單的「會」或「不會」：**有醫師處方、來源合法的中藥，和來路不明的偏方、草藥、自己熬的青草茶，風險完全不同。**這篇說明真正被證實會傷腎的是哪些東西（馬兜鈴酸、重金屬、摻入西藥的偏方、楊桃），腎臟病人為什麼要特別注意鉀離子和甘草，以及看中醫時怎麼保護自己。

分類：用藥安全

重點問題：吃中藥會不會傷腎？腎臟不好可以看中醫嗎？
重點答案：**風險主要來自「來路不明」，而不是「中藥」這兩個字。** 被證實會造成嚴重腎損傷的包括：**含馬兜鈴酸的藥材**（台灣已在 2003 年禁用五種）、**受重金屬汙染的產品**、**偷偷摻入類固醇或止痛藥的偏方**，以及**楊桃**。已經有腎臟病的人，還要注意**部分湯劑與青草茶的鉀離子**、以及**甘草造成的高血壓與低血鉀**。目前**沒有任何中藥被證實能逆轉慢性腎臟病**。
重點行動：只在**合格中醫師處方**下使用、**有許可證字號的中藥**；**主動告訴中醫師與西醫師你的腎功能和所有正在吃的藥**；不吃偏方、秘方、網路或電台販售的「補腎」「排毒」產品；**腎臟病人不要吃楊桃、不要喝楊桃汁**；吃中藥期間照常抽血追蹤腎功能與鉀離子。

「醫師，我可以吃中藥嗎？聽說中藥會傷腎。」

「醫師，我腎臟不好，想吃中藥調一調，把腎功能補回來。」

這兩種問題幾乎每天都會聽到，而且常常來自同一位病人。一邊擔心中藥傷腎，一邊又希望中藥能救腎——兩種想法都有一部分道理，也都有一部分誤解。

這篇不是要說中藥好或不好，而是把**已經被證實的風險**講清楚，讓你知道該避開什麼、該問什麼。

## 最有名的例子：馬兜鈴酸

### 一個改變全世界草藥管理的事件

1990 年代初期，比利時一家減重診所的病人中，陸續出現**快速惡化的腎衰竭**，不少人最後需要洗腎或換腎，之後還有一部分人發生**泌尿道上皮癌**。

追查的結果發現：減重配方裡原本應該使用的藥材，被**名稱相近、但含有馬兜鈴酸的另一種藥材**取代了。這種腎病變一開始被稱為「中草藥腎病變」，後來因為致病物質明確，改稱為**馬兜鈴酸腎病變**。

### 馬兜鈴酸會造成什麼

- **腎臟間質纖維化**：腎功能可能在幾個月到幾年內持續下降，而且**停藥之後仍可能繼續惡化**
- **泌尿道上皮癌**：特別是腎盂與輸尿管的癌症。研究曾在台灣上泌尿道上皮癌病人的腫瘤中，找到馬兜鈴酸造成的特徵性基因突變
- 國際癌症研究機構將馬兜鈴酸列為**對人類確定致癌的物質**

### 台灣的管理

台灣在 **2003 年**公告禁止使用含馬兜鈴酸的**廣防己、青木香、關木通、馬兜鈴、天仙藤**五種藥材。合法的中藥廠與中醫院所使用的藥材，受到這項規定的管制。

**真正的風險在管制之外**：自己上山採的草藥、國外帶回來或網路購買的產品、民間流傳的偏方、來源不明的「祖傳秘方」。名稱相近、外觀相似的藥材被混用，正是比利時事件的起點。

## 其他被證實的風險

### 一、重金屬汙染

鉛、汞、砷、鎘等重金屬會傷害腎小管。合法的中藥製劑有重金屬含量的檢驗規範；**風險主要來自沒有經過檢驗的產品**，例如來源不明的藥丸、藥粉，或標榜某些礦物成分的偏方。

### 二、偏方裡偷偷加了西藥

**這是台灣很實際的問題。** 衛生主管機關多次查獲號稱「純中藥」「天然草本」的產品，裡面其實摻了：

- **類固醇**：吃了關節不痛、精神變好、食慾大開，所以被認為「很有效」；長期使用會造成血糖血壓上升、骨質疏鬆、感染
- **消炎止痛藥（NSAID）**：止痛效果明顯，但會傷腎，對腎功能不好的人尤其危險，見[止痛藥那一篇](/articles/painkiller-nsaid-kidney.html)
- 其他各式西藥成分

**吃了「效果特別好」的不明產品，反而要提高警覺。**

### 三、楊桃——腎友絕對不能碰

楊桃不是中藥，但它常被當成**潤喉、止咳的民間偏方**（楊桃汁），所以一起講。

楊桃含有**神經毒素**和**大量草酸**：

- **腎功能不好的人**，毒素排不掉，可能出現**頑固性打嗝、意識混亂、肌肉無力、抽搐**，嚴重時會致命——台灣曾有不少病例報告
- **大量的草酸**可能沉積在腎小管，造成**急性腎損傷**——即使是腎功能原本正常的人，**空腹大量喝楊桃汁**也曾發生

**慢性腎臟病人與透析病人，請完全避免楊桃、楊桃汁與含楊桃的產品。**

### 四、甘草——血壓與鉀離子

甘草是很常見的中藥成分，也存在於某些涼茶、零食與甘草製品中。甘草裡的**甘草酸**會產生類似醛固酮的作用：

- **血壓上升**
- **低血鉀**（肌肉無力、心律不整）
- **水腫**

偶爾、少量通常不是問題；但**長期、大量**，或本身有高血壓、心臟病、腎臟病、正在吃利尿劑的人，需要特別注意。

### 五、鉀離子——腎臟病人的隱藏風險

**已經有慢性腎臟病的人**，腎臟排鉀能力下降。部分**藥材熬煮的湯劑、某些青草茶、精力湯或濃縮的植物萃取**，鉀離子含量可能不低，再加上一些常見的護腎藥物也會讓鉀上升，就可能發生**高血鉀**——嚴重時會造成心律不整。高血鉀的完整說明見[高血鉀那一篇](/articles/high-potassium-ckd.html)。

### 六、和西藥的交互作用

部分草藥會影響西藥的代謝。對**換過腎、正在吃抗排斥藥**的人尤其重要：抗排斥藥的濃度太高會傷腎，太低則會排斥。**換腎病人吃任何草藥或保健食品之前，都要先問移植團隊。**正在吃抗凝血藥的人也一樣，有些草藥會增加出血風險。

## 那麼，腎臟不好可以看中醫嗎？

**可以，但要有三個前提：**

1. **合格的中醫師、合法的藥**：在中醫院所由中醫師開立處方，使用**有衛福部許可證字號**的中藥（科學中藥或合法飲片）
2. **雙向告知**：把你的**腎功能（eGFR）、鉀離子、正在吃的所有西藥**告訴中醫師；也把**正在吃的中藥告訴腎臟科醫師**
3. **持續追蹤**：吃中藥期間，**照常回腎臟科抽血**，看腎功能與鉀離子有沒有變化。若數值變差，兩邊都要知道

台灣有不少醫院同時有中醫部與腎臟科，可以在同一家醫院看，資訊比較容易互通。

### 但請不要期待「把腎功能補回來」

**目前沒有任何中藥、草藥或保健食品，經過嚴謹的臨床試驗證實能逆轉慢性腎臟病，或讓人免於透析。** 宣稱「不用洗腎」「腎功能恢復」「排毒」的產品與療程，請特別小心，見[那些號稱「不用洗腎」的療法](/articles/no-dialysis-therapy-claims.html)。

真正被證實能延緩腎功能下降的，是**控制血壓、控制血糖、降低蛋白尿，以及使用 ACEI／ARB、SGLT2 抑制劑等護腎藥物**，見[真正有證據的護腎習慣](/articles/kidney-lifestyle-evidence.html)與[SGLT2 抑制劑那一篇](/articles/sglt2-kidney-protection.html)。**不要因為吃中藥而停掉這些藥。**

## 一張自我檢查表

吃任何中藥、草藥或「天然」產品之前，問自己：

| 問題 | 如果答案是「否」或「不知道」 |
|---|---|
| 是合格中醫師開的處方嗎？ | 風險明顯較高 |
| 產品上有許可證字號嗎？ | 來源與成分無法確認 |
| 我知道裡面有哪些成分嗎？ | 無法評估風險 |
| 中醫師知道我的腎功能與正在吃的西藥嗎？ | 請補上 |
| 腎臟科醫師知道我在吃這個嗎？ | 請補上 |
| 效果是不是「好得不尋常」？ | 若是，要懷疑摻了西藥 |

## 常見問題與誤解

### 科學中藥比較安全嗎？

科學中藥是在 GMP 藥廠製造、經過濃縮的製劑，**品質管理與檢驗較完整**，比來源不明的藥材可靠。但「科學中藥」不代表對腎臟病人一定安全——**劑量、成分、鉀離子與交互作用仍然需要評估**，處方時請讓中醫師知道你的腎功能。

### 中藥可以治療腎臟病嗎？

目前沒有中藥被證實能逆轉慢性腎臟病。部分研究在探討特定中藥的效果，但證據還不足以取代標準治療。**可以把中醫當作輔助、改善症狀的選擇，但不要因此停掉護腎的西藥，或延誤透析與移植的準備。**

### 雞精、滴雞精、保健食品算不算？

這些不屬於中藥，但腎臟病人一樣要注意：**蛋白質、鉀、磷的含量**可能不低，還要算進每日的總量。透析病人與晚期腎臟病人，請先和營養師討論。蛋白質的建議見[腎臟病蛋白質要吃多少](/articles/protein-intake-ckd.html)。

### 夏天喝青草茶、涼茶退火可以嗎？

腎功能正常的人偶爾喝通常沒有問題。**已經有慢性腎臟病，或是透析病人**，要注意兩件事：**鉀離子**（部分青草茶含量不低）和**甘草**（涼茶常見）。透析病人還要把液體量算進限水的額度。

### 吃中藥之後腎功能變差，該怎麼辦？

**先停掉來路不明的產品，盡快回腎臟科抽血**，並把產品（包裝、藥袋、剩下的藥）一起帶去。若是中醫師處方，也請同時告知中醫師。腎功能的變化需要找出原因，有時是藥物，有時是同一段時間的脫水、感染或其他藥物造成。

## 現在可以做的三件事

- **只用合格中醫師處方、有許可證字號的中藥。** 不吃偏方、秘方、自己採的草藥，以及網路或電台販售的「補腎」「排毒」產品——馬兜鈴酸、重金屬與摻入的西藥，都藏在這些地方。
- **兩邊都要知道：把腎功能和所有西藥告訴中醫師，把中藥告訴腎臟科醫師。** 吃中藥期間照常抽血追蹤腎功能與鉀離子，換過腎的人吃任何草藥前先問移植團隊。
- **腎臟病人不要碰楊桃，留意甘草與高鉀湯劑。** 也不要因為吃中藥而停掉控制血壓、血糖與保護腎臟的西藥。
