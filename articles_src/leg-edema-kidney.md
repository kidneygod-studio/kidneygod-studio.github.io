# 腳水腫是腎臟病嗎？從按壓的凹痕看出原因

> 腳踝一按一個凹，很多人第一個想到的是「腎臟壞了」。其實**腳水腫最常見的原因是久站久坐、靜脈回流變差和藥物**，腎臟只是其中一個可能。這篇說明怎麼從「單腳還是雙腳、什麼時候腫、有沒有其他症狀」初步分辨原因，哪些情況要當天就醫，以及看醫師時該驗哪些項目。

分類：警訊與迷思

重點問題：腳踝下午會腫、按下去有凹痕，是不是腎臟出問題了？
重點答案：**不一定，而且多半不是。** 雙腳傍晚腫、早上消，最常見的是久站久坐與靜脈回流變差；**降血壓藥（尤其是 amlodipine 這類鈣離子阻斷劑）、止痛藥、某些糖尿病藥與神經痛藥**也常造成水腫。腎臟引起的水腫通常會**合併泡泡尿、眼皮早上腫、全身性的腫**，驗尿就能大致分辨。**單腳突然腫痛發熱，要當天就醫**，那可能是深部靜脈血栓。
重點行動：先觀察三件事：**單腳或雙腳、早上還是傍晚腫、有沒有喘或泡泡尿**；回診時請醫師安排**尿液檢查（含尿蛋白或 UACR）、肌酸酐與 eGFR、白蛋白、肝功能**，必要時加驗心臟功能；**不要自己買利尿劑來消腫**。

「醫師，我腳腫，是不是腎臟不好？」

這是腎臟科門診最常聽到的一句話之一。腳腫的人確實應該檢查腎臟，但檢查完之後，很多人會發現原因根本不在腎臟——而是**每天站八小時、剛換了一種降血壓藥，或是靜脈本來就不好**。

腳腫是一個「症狀」，不是一個「診斷」。同樣是腳踝一按一個凹，背後的原因可以從完全無害到需要立刻處理。這篇的目的，是讓你在看醫師之前，先對自己屬於哪一類有個方向。

## 先確定是不是「凹陷性水腫」

用大拇指**在小腿前側骨頭上（脛骨）或腳踝內側，用力按壓 5 到 10 秒**，放開後：

- **留下凹痕、慢慢才回彈**：凹陷性水腫，代表皮下組織裡積了多餘的水分。這是這篇主要討論的狀況
- **按不下去、皮膚硬硬的**：比較像淋巴水腫、甲狀腺功能低下造成的黏液性水腫，或是脂肪組織，原因和處理方向不同
- **只是襪子勒痕**：傍晚出現襪痕很常見，單獨存在不代表有病

另一個簡單的指標是**體重**：幾天內體重增加一到兩公斤以上，而且吃得沒有比較多，多半是水。

## 第一個分辨點：單腳還是雙腳

### 單腳腫——先排除血栓

**只有一隻腳腫，尤其是突然出現、合併疼痛、發紅、發熱、小腿一捏就痛**，要先想到**深部靜脈血栓**。血栓如果剝落跑到肺部，會造成肺栓塞，是會致命的急症。

長途飛行或久坐、剛開過刀、骨折打石膏、癌症、懷孕或產後、服用含雌激素的藥物，都會提高血栓風險。**這種情況請當天就醫，不要等門診。**

單腳腫的其他原因還有蜂窩性組織炎（皮膚紅熱痛、可能發燒）、外傷、膝蓋後方的囊腫破裂、靜脈曲張集中在單側、或骨盆腔腫瘤壓迫。

### 雙腳腫——才需要想到全身性的原因

腎臟、心臟、肝臟、甲狀腺與藥物造成的水腫，**幾乎都是雙側的**。所以如果你是兩腳都腫、而且沒有疼痛發紅，接下來才需要往下面這些原因去找。

## 第二個分辨點：什麼時候腫

| 腫的時間與樣子 | 比較常見的原因 |
|---|---|
| **傍晚腫、早上起床就消** | 久站久坐、靜脈回流變差、藥物、天氣熱 |
| **早上起床眼皮腫，白天往下移到腳** | 腎臟（尤其大量蛋白尿時）——躺平一整晚，水分會分布到臉部 |
| **躺平會喘、要墊高枕頭才睡得著，腳也腫** | 心臟衰竭 |
| **肚子越來越大、腳也腫** | 肝硬化、心臟衰竭，或嚴重的腎病症候群 |
| **吃了某種新藥之後幾週開始腫** | 藥物引起的水腫 |

這張表只是方向，不是診斷——實際上常常有兩三個原因疊在一起，例如年紀大、靜脈本來就不好，又在吃鈣離子阻斷劑。

## 最常見的原因，其實不是腎臟

### 一、久站、久坐與靜脈功能不全

小腿肌肉收縮是把下肢血液「擠」回心臟的幫浦。久站或久坐不動，靜脈裡的壓力上升，水分就會滲到組織裡。**靜脈瓣膜功能變差**（常見於年紀大、懷孕過、體重較重、有靜脈曲張的人）會讓這個現象更明顯。

這種水腫的特徵是**傍晚最明顯、睡一覺就消**，長期可能合併小腿皮膚變暗、癢、甚至潰瘍。

### 二、藥物——很常被忽略

| 藥物類別 | 說明 |
|---|---|
| **鈣離子阻斷劑**（例如 amlodipine、nifedipine） | **最常見的藥物性水腫**。它讓小動脈擴張、但靜脈端沒有跟著擴張，水分被「擠」到組織裡。劑量越高越常見 |
| **消炎止痛藥（NSAID）** | 讓腎臟留鈉留水，也會讓血壓上升。對腎臟不好的人還有額外風險，見[止痛藥那一篇](/articles/painkiller-nsaid-kidney.html) |
| **pioglitazone**（一種糖尿病藥） | 造成水分滯留，心臟衰竭的人要特別小心 |
| **gabapentin、pregabalin**（神經痛藥） | 腳腫是常見副作用 |
| **類固醇、某些荷爾蒙藥物** | 留鈉留水 |

**鈣離子阻斷劑引起的水腫有一個特點：吃利尿劑通常消不太掉**，因為問題不是身體的水太多，而是血管的壓力分布。常見的處理方式是調降劑量、換藥，或併用 ACEI／ARB 類的降血壓藥（它能擴張靜脈端，減輕水腫）。**請和開藥的醫師討論，不要自己停藥**——血壓失控的風險比腳腫大得多。

### 三、心臟衰竭

心臟打不動，血液回流受阻，水分積在下肢與肺部。線索是**走路或爬樓梯變喘、躺平會喘、半夜喘醒、需要墊高枕頭**。這種情況需要驗心臟相關的指標（例如 BNP）並做心臟超音波。

### 四、肝臟疾病

肝硬化時，血中白蛋白下降、腹腔內壓力上升，常常是**腹水比腳腫更明顯**。

### 五、甲狀腺功能低下

會造成按不太下去的黏液性水腫，常合併怕冷、疲倦、體重增加、便秘、皮膚乾燥。

## 什麼時候真的是腎臟

腎臟造成的水腫主要有兩種情況：

### 一、大量蛋白尿（腎病症候群）

腎臟的過濾網破了洞，大量白蛋白從尿中流失，血中白蛋白下降，水分就留不住在血管裡。特徵是：

- **尿很多泡泡、而且久久不散**（見[泡泡尿那一篇](/articles/foamy-urine-proteinuria.html)）
- **早上眼皮腫，接著腳、甚至全身都腫**
- 體重在幾週內明顯上升

這種情況**驗一次尿就能看出端倪**，需要腎臟科進一步評估原因，有時需要腎臟切片。

### 二、腎功能已經明顯下降

腎臟排鈉排水的能力下降，喝進去、吃進去的鹽和水排不掉。通常是腎功能已經到比較後期，會合併血壓變難控制、尿量改變。

**換句話說：早期慢性腎臟病通常不會腳腫。** 如果你的 eGFR 是 60 出頭、尿蛋白正常，腳腫的原因多半在別的地方。eGFR 的意義見[這一篇](/articles/egfr-meaning-ckd-stages.html)。

## 這些情況請當天就醫

- **單腳突然腫痛、發紅發熱**——可能是深部靜脈血栓或蜂窩性組織炎
- **腫合併喘、胸悶、躺平會喘**——可能是心臟衰竭或肺水腫
- **尿量明顯減少，或幾天內體重增加好幾公斤**
- **全身快速水腫合併大量泡泡尿**
- **腫的部位皮膚破皮、流水、發燒**

## 看醫師時，通常會檢查什麼

| 檢查 | 看什麼 |
|---|---|
| **尿液檢查、尿蛋白或 UACR** | 有沒有蛋白尿——分辨是不是腎臟的第一步，判讀見[尿液檢查報告那一篇](/articles/urinalysis-report-guide.html) |
| **肌酸酐、eGFR** | 腎功能 |
| **血中白蛋白** | 太低會讓水分留不住 |
| **肝功能** | 肝臟原因 |
| **BNP 或 NT-proBNP、心臟超音波** | 心臟衰竭（依症狀安排） |
| **甲狀腺功能（TSH）** | 甲狀腺功能低下（依症狀安排） |
| **下肢靜脈超音波** | 單腳腫時排除血栓、評估靜脈功能 |

**記得把目前吃的所有藥帶去**，包含保健食品和外面買的止痛藥。很多時候答案就在藥袋裡。

## 在家可以做的事

- **減鹽**：鈉會把水留在身體裡，這對所有原因的水腫都有幫助。外食減鈉的實際做法見[外食減鈉那一篇](/articles/taiwan-eating-out-sodium.html)
- **抬腿**：休息時把腳抬到比心臟高，每次 20 到 30 分鐘
- **動小腿**：久坐時每小時起來走一走，坐著也可以做踮腳尖、勾腳板的動作，讓小腿肌肉幫浦工作
- **彈性襪**：對靜脈功能不全造成的水腫有效，但**有周邊動脈阻塞（走路小腿會痛、腳摸起來冰冷、腳背脈搏摸不到）的人不適合**，糖尿病人穿之前也建議先問醫師
- **每天同一時間量體重**：比看腳腫了幾分更客觀

## 常見問題與誤解

### 可以自己買利尿劑來消腫嗎？

**不建議。** 利尿劑會讓腳看起來消了，但如果原因是靜脈或鈣離子阻斷劑，它本來就效果有限；如果原因是心臟、肝臟或腎臟，**不知道原因就用藥，等於把線索蓋掉**。利尿劑還可能造成脫水、低血鉀、低血鈉，甚至讓腎功能惡化。標榜「消水腫」的茶飲與保健食品也一樣，原因找出來比消腫重要。

### 腳腫是不是要少喝水？

**要看原因。** 心臟衰竭、低血鈉、腎功能很差或已經透析的人，醫師可能會要你限水；但多數靜脈或藥物造成的水腫，**限水沒有幫助，減鹽才有**。自己亂限水，在天熱或腹瀉時反而容易脫水傷腎。完整說明見[一天到底要喝多少水](/articles/water-intake-kidney.html)。

### 吃降血壓藥之後腳開始腫，要停藥嗎？

**請不要自己停。** 先回診告訴醫師腫是什麼時候開始的。如果是鈣離子阻斷劑，常見的做法是減量、換藥或加一種能抵消水腫的降壓藥；血壓若因停藥而失控，中風與心臟病的風險遠比腳腫嚴重。

### 早上起床眼皮腫，是腎臟有問題嗎？

前一晚吃得鹹、睡前喝很多水、哭過、睡不好，都會讓早上眼皮腫，偶爾一次不必擔心。但如果**幾乎每天都腫，而且合併泡泡尿或腳也腫**，就值得驗一次尿。

### 腳腫但檢查都正常，那怎麼辦？

這其實很常見，最可能的答案是**靜脈回流與生活型態**。持續減鹽、多動小腿、適時抬腿、考慮穿彈性襪；如果在吃鈣離子阻斷劑，和醫師討論調整。若腫越來越嚴重或出現新的症狀，再回頭檢查。

## 現在可以做的三件事

- **先觀察，再就醫：單腳或雙腳、什麼時候腫、有沒有喘或泡泡尿。** 單腳突然腫痛或合併喘，請當天就醫；其他情況帶著觀察結果去門診，醫師能更快找到方向。
- **驗一次尿和腎功能，把腎臟排除或確認。** 尿蛋白（最好是 UACR）、肌酸酐與 eGFR、白蛋白，就能分辨大部分「是不是腎臟」的問題；同時把所有的藥帶去讓醫師看。
- **減鹽、動小腿、不要自己吃利尿劑。** 減鹽對每一種水腫都有幫助；利尿劑和「消水腫」產品會蓋掉線索，原因找出來之前不要自己用。
