# 洗腎皮膚好癢怎麼辦？腎因性搔癢的原因與治療

> 皮膚癢到睡不著、抓到破皮，是很多透析病人和晚期腎臟病人說不出口的痛苦。這種「腎因性搔癢」不只是皮膚乾，和**尿毒素、磷與副甲狀腺、免疫與神經訊號**都有關係。這篇說明為什麼會癢、要先排除哪些其他原因、皮膚照顧怎麼做才有用，以及**透析是否足夠、控磷、和幾種被證實有效的藥物**該怎麼和醫師討論。

分類：生活習慣

重點問題：洗腎之後皮膚一直癢，擦藥吃藥都沒用，該怎麼辦？
重點答案：腎因性搔癢**很常見，但不是「只能忍」**。處理要分層進行：**先做好皮膚保濕與洗澡習慣**；**檢查透析是否足夠、磷與副甲狀腺素是否偏高**；**排除其他原因**（肝膽疾病、缺鐵、藥物過敏、疥瘡、皮膚病）。仍然很癢時，**低劑量的 gabapentin 或 pregabalin**、**窄頻 UVB 照光**、以及部分國家已核准的**專門針對尿毒搔癢的藥物**，都可以和醫師討論。一般的抗組織胺效果常常有限。
重點行動：**把癢的程度、時間、影不影響睡眠告訴透析團隊**——很多人從沒主動提；每天洗澡後三分鐘內擦**無香料保濕劑**、水溫不要太熱；**看最近的磷、副甲狀腺素與透析效率（Kt/V）**；不要自己買強效類固醇藥膏長期擦，也不要自行加重神經痛藥的劑量。

「醫師，我每天晚上癢到睡不著，抓到流血，可是不好意思講。」

在透析室，這是很常見卻很少被主動提起的困擾。很多人以為這是洗腎「本來就會有」的事，只能忍；也有人擦了好幾種皮膚藥膏都沒用，就放棄了。

**腎因性搔癢（也稱為尿毒搔癢）是一個被正式研究的醫學問題**，它會影響睡眠、情緒與生活品質，研究也發現嚴重搔癢和較差的整體預後有關。好消息是：**它有方法可以改善**，只是需要一步一步來。

## 有多常見

大型國際研究中，**約三到四成的血液透析病人表示受到中度以上的搔癢困擾**；腹膜透析與尚未透析的晚期慢性腎臟病人也會發生，只是比例稍低。

腎因性搔癢的特徵常常是：

- **兩側對稱**，常見於背部、手臂、腿部，也可能全身
- **晚上比較嚴重**，影響入睡或半夜癢醒
- 有些人在**透析當中或透析後**特別癢，有些人則是透析前最癢
- 長期抓癢會留下**抓痕、結痂、皮膚變厚變黑**，甚至形成硬硬的結節

## 為什麼會癢

腎因性搔癢的原因不是單一一個，目前認為是幾種機轉疊在一起：

| 可能的原因 | 說明 |
|---|---|
| **尿毒素累積** | 腎臟排不掉的代謝物，可能刺激皮膚的神經末梢 |
| **皮膚乾燥** | 腎臟病人汗腺與皮脂腺的功能改變，皮膚屏障變差，**超過一半的透析病人皮膚明顯乾燥** |
| **磷與副甲狀腺素偏高** | 血磷高、鈣磷乘積高、副甲狀腺亢進都和搔癢有關 |
| **免疫系統失調** | 發炎相關的訊號分子增加，刺激癢的神經傳導 |
| **體內鴉片類訊號失衡** | 神經系統裡「促進癢」與「抑制癢」的兩種訊號不平衡——這也是新一代藥物的作用目標 |
| **透析不足** | 毒素清除不夠時，搔癢可能更明顯 |

## 第一步：先排除其他原因

不是所有腎臟病人的癢，都是腎臟造成的。醫師通常會先確認：

- **肝膽疾病**：膽汁滯留會造成很明顯的癢，B、C 型肝炎在透析病人並不少見
- **缺鐵**：缺鐵本身就可能造成搔癢，腎臟病人很常缺鐵，見[腎性貧血那一篇](/articles/ckd-anemia.html)
- **藥物過敏**：新開始的藥物，包括抗生素、降血壓藥、止痛藥，甚至透析時使用的某些材料
- **疥瘡**：特別是住在護理機構、家人也在癢的人；指縫、手腕、腰部最明顯，夜間更癢
- **皮膚疾病**：異位性皮膚炎、乾癬、黴菌感染、蕁麻疹
- **甲狀腺疾病、血液疾病、糖尿病的神經病變**

**如果有明顯的紅疹、水泡、皮膚脫屑、或家人一起癢，請告訴醫師**，那比較不像典型的腎因性搔癢。

## 第二步：皮膚照顧——基礎，但很重要

這一步看起來簡單，卻是所有治療的地基。**皮膚乾燥本身就會讓癢加重**，而保濕是最安全、最便宜的方法。

### 洗澡

- **水溫溫的就好**，不要太熱——熱水當下很舒服，但會帶走皮脂，之後更乾更癢
- **時間短一點**，十分鐘以內
- 用**溫和、低刺激、無香料**的清潔產品，不需要每次全身都用肥皂
- **不要用力搓、不要用菜瓜布或澡巾**
- 用毛巾**輕輕壓乾**，不要來回擦

### 保濕

- **洗完澡後三分鐘內**，趁皮膚還有點濕時擦上保濕劑
- 選擇**無香料、無酒精**的乳霜或軟膏，質地越滋潤通常效果越好
- **一天至少擦兩次**，乾燥的季節或冷氣房裡更要擦
- 有洞管或導管的部位，依透析團隊的照護指示，不要把乳液擦在傷口上

### 其他小技巧

- **指甲剪短、磨平**，晚上可以戴棉質手套，減少抓破
- 穿**寬鬆、棉質**的衣服，避免毛料直接接觸皮膚
- 室內保持適當濕度，冷氣房可以放一盆水或使用加濕器
- 癢的時候可以**冰敷或用涼的濕毛巾**，取代抓

## 第三步：把透析和控磷做好

### 透析是否足夠

透析效率通常用 **Kt/V** 或尿素下降比例來評估（BUN 在透析中的意義見[BUN 那一篇](/articles/bun-high.html)）。如果透析效率不夠，醫師可能會調整：

- 透析時間或次數
- 血流速度
- 人工腎臟的規格

**不要自己縮短透析時間或跳過透析**——毒素累積只會讓癢更嚴重。

### 控制磷與副甲狀腺素

血磷偏高與副甲狀腺亢進都和搔癢有關。控制的方法包括：

- **飲食控磷**：特別注意加工食品裡的磷添加物，見[高血磷那一篇](/articles/high-phosphorus-ckd.html)
- **按時吃降磷藥**：要和餐點一起吃才有效
- 依醫師建議使用控制副甲狀腺的藥物

## 第四步：藥物與其他治療

當前面幾步都做了還是很癢，可以和醫師討論以下選項：

### 一、外用藥

- **保濕劑**仍是基礎
- **含止癢成分的外用藥**（例如含薄荷醇、局部麻醉成分的產品）可以短期舒緩
- **類固醇藥膏**對腎因性搔癢的效果有限，適合有明確皮膚發炎的時候短期使用。**長期大面積擦強效類固醇會讓皮膚變薄**，請不要自己買來長期使用

### 二、gabapentin 與 pregabalin

這兩種原本是神經痛的藥，**在腎因性搔癢的臨床試驗中顯示能減輕癢**，是常用的選擇之一。但要注意：

- 它們**經由腎臟排出**，腎臟病人與透析病人**必須使用很低的劑量**（例如只在透析後服用）
- 常見副作用是**嗜睡、頭暈、步態不穩**，長輩要特別小心跌倒
- **請不要自己加量**，也不要拿別人的藥來吃

### 三、專門針對尿毒搔癢的藥物

近年有藥物是**針對體內鴉片類訊號失衡**而設計的：

- **difelikefalin**：一種在透析後經由靜脈給予的藥物，在美國、歐洲等地已核准用於血液透析病人的中重度搔癢
- **nalfurafine**：一種口服藥，在日本等地使用多年

這些藥物在台灣是否可取得、是否有健保給付，**請直接問你的透析團隊**，情況可能隨時間改變。

### 四、窄頻 UVB 照光治療

在皮膚科進行的**窄頻紫外線 B 照光**，對部分病人有效，通常需要每週幾次、持續一段時間。皮膚較白或有皮膚癌病史的人，請和皮膚科醫師討論風險。

### 五、抗組織胺

一般的抗組織胺（過敏藥）**對腎因性搔癢的效果常常有限**，因為這種癢主要不是組織胺造成的。有鎮靜作用的抗組織胺可能幫助入睡，但年長者要注意嗜睡、跌倒與意識混亂。

### 六、腎臟移植

**成功的腎臟移植通常能讓腎因性搔癢明顯改善**，這也是移植能改善生活品質的原因之一，見[腎臟移植那一篇](/articles/kidney-transplant-guide.html)。

## 不要忽略的：睡眠與情緒

長期搔癢會讓人睡不好、情緒低落、焦慮，甚至影響參與透析的意願。**請把這些也告訴醫療團隊**——改善睡眠與情緒，本身也能讓搔癢比較容易忍受；必要時可以轉介身心科協助。

## 常見問題與誤解

### 皮膚癢是不是因為洗腎洗得不乾淨？

**透析不足確實可能讓癢加重**，但多數腎因性搔癢是多種原因共同造成的，即使透析效率正常也可能發生。請醫師看你的 Kt/V，如果足夠，就要往其他方向找原因與治療。

### 可以吃一般的止癢藥（過敏藥）就好嗎？

可以試，但**效果常常不理想**，因為腎因性搔癢主要不是過敏反應。若吃了沒有改善，請和醫師討論其他方法，而不是一直加量。

### 可以用中藥或草藥泡澡止癢嗎？

部分草藥外用可能刺激皮膚或造成過敏，口服草藥則可能有**鉀離子與其他成分**的問題。透析病人使用前，請先和醫療團隊討論，見[中藥會傷腎嗎](/articles/herbal-medicine-kidney.html)。

### 少吃海鮮、少吃「發物」可以止癢嗎？

除非你對特定食物過敏，否則**忌口通常對腎因性搔癢沒有明確幫助**。真正和癢有關的飲食重點是**控制磷**——加工食品、飲料裡的磷添加物影響最大。

### 癢會不會好？

**多數人在綜合處理後能明顯改善，但不一定完全消失。** 目標是讓癢降到不影響睡眠與生活的程度。持續和透析團隊溝通、定期評估，比一個人默默忍耐有效得多。

## 現在可以做的三件事

- **主動告訴透析團隊：你有多癢、什麼時候最癢、會不會影響睡覺。** 很多人沒說，就一直沒被處理。也請醫師排除肝膽疾病、缺鐵、藥物過敏與疥瘡等其他原因。
- **從皮膚照顧開始：溫水短時間洗澡，洗完三分鐘內擦無香料保濕劑，一天至少兩次。** 指甲剪短，用冰敷取代抓。
- **看你的磷、副甲狀腺素和 Kt/V，再和醫師討論藥物。** 低劑量 gabapentin 或 pregabalin、照光治療與專門的止癢藥物都是選項，但劑量必須由醫師調整，不要自己加。
